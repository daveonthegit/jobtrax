Lab 9 — Aggregate operations & window functions

SQLite + Flask. On first run, the app creates mydatabase.db with lab sample data if that file does not exist. Delete mydatabase.db to get a fresh database on next start. On PythonAnywhere, cd to your project folder (e.g. mysite) and open the same database in the console.

Aggregates

  • COUNT(*) — women
  • COUNT(*) vs COUNT(member_coach_id)
  • COUNT(DISTINCT member_coach_id)
  • AVG() and ROUND()
  • MAX, MIN, AVG
  • GROUP BY — entries per member
  • Nested query — handicap > average
  • Nested aggregate — AVG of per-member counts

Window functions

  • ROW_NUMBER() OVER (…) — handicap rank
